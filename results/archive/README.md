# Archived result bundles

Historical benchmark results. **Not all of these are superseded**:
`e1_raccess_exact_2026-09-10` and `e3_long_scaling_2026-09-10` are still
active manuscript evidence (exact-mode validation, \S3.1, and the SARS-CoV-2
169s timing figure, \S3.3, respectively) -- they ended up here alongside
genuinely-superseded bundles during a 2026-09-15 cleanup pass, which was a
mistake caught by a later review round. See `provenance.json` and
`summary.json` in this directory for what each subdirectory is, whether it is
still cited, and pointers to the other current evidence bundles.
